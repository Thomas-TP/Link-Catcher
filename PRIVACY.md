# Politique de confidentialité / Privacy Policy

_Dernière mise à jour / Last updated : 2026-11-11_

## Français

**Link Catcher ne collecte, ne transmet et ne vend aucune donnée personnelle.**

- Vos raccourcis (mot-clé → URL) et vos préférences (thème, langue, moteur de repli, ordre) sont enregistrés uniquement via l'API de stockage du navigateur (`storage.sync`). Si la synchronisation est activée dans votre navigateur (compte Google ou Microsoft), c'est le navigateur lui-même qui les synchronise entre vos appareils ; l'extension n'envoie rien à un serveur.
- Un compteur d'utilisation par raccourci est conservé localement sur l'appareil (`storage.local`) et n'est jamais synchronisé.
- L'extension lit l'URL d'une navigation **uniquement** pour détecter une recherche sur un moteur supporté (Google, Bing, DuckDuckGo, Yahoo, Ecosia, Brave, Startpage, Qwant, Kagi) et la comparer à vos mots-clés, localement. Aucun historique n'est enregistré ni transmis.
- Aucun outil d'analyse, aucune publicité, aucun traceur, aucun code distant, aucune police ou ressource chargée depuis Internet.
- L'export JSON est un fichier local que vous contrôlez.

Pour effacer toutes vos données : onglet **Données → Supprimer tout**, ou désinstallez l'extension.

Contact : via le profil GitHub de [@Thomas-TP](https://github.com/Thomas-TP) ou une issue sur le dépôt.

## English

**Link Catcher does not collect, transmit or sell any personal data.**

- Your shortcuts (keyword → URL) and preferences (theme, language, fallback engine, order) are stored only through the browser's storage API (`storage.sync`). If browser sync is enabled (Google or Microsoft account), the browser itself syncs them across your devices; the extension never sends anything to a server.
- A per-shortcut usage counter is kept locally on the device (`storage.local`) and is never synced.
- The extension reads a navigation URL **only** to detect a search on a supported engine (Google, Bing, DuckDuckGo, Yahoo, Ecosia, Brave, Startpage, Qwant, Kagi) and match it locally against your keywords. No history is stored or transmitted.
- No analytics, ads, trackers, remote code, or fonts/resources loaded from the Internet.
- JSON export is a local file under your control.

To erase all your data: **Data → Clear all data**, or uninstall the extension.

Contact: through the GitHub profile of [@Thomas-TP](https://github.com/Thomas-TP) or an issue on the repository.
