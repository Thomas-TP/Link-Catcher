## Description détaillée (1876 caractères)
Link Catcher transforme votre barre de recherche en lanceur pour les sites que vous visitez chaque jour.

Enregistrez un mot-clé et une URL (par exemple « gh » → github.com). Tapez ensuite ce mot dans Google, Bing, DuckDuckGo, Yahoo, Ecosia, Brave, Startpage, Qwant ou Kagi — ou « l » + Espace + mot dans la barre d'adresse — et vous arrivez directement sur votre page, avant même le chargement des résultats.

FONCTIONNALITÉS
• Redirection instantanée sur un mot exact (insensible à la casse et aux accents)
• Barre d'adresse (omnibox) avec suggestions en direct : « l », Espace, puis quelques lettres
• Alias : écrivez « docs, d » pour créer deux mots-clés vers le même lien
• Recherche, tri (A-Z / Z-A), vue liste ou grille, ordre manuel par glisser-déposer
• Import / export JSON, avec gestion des conflits (garder les vôtres ou remplacer)
• Thèmes clair et sombre ; English, Français, Español, Deutsch
• Raccourci clavier Alt+Maj+L pour ouvrir le gestionnaire
• Choix du moteur de recherche utilisé quand un mot est inconnu
• Compteur d'utilisation local pour chaque raccourci (jamais synchronisé)

LA VIE PRIVÉE D'ABORD
Pas de compte, pas d'analyse, pas de suivi, pas de code distant, aucune police ni ressource externe. Vos raccourcis restent dans votre navigateur (synchronisés par celui-ci uniquement si vous activez la synchronisation). L'extension n'a besoin que de deux permissions : « storage » pour enregistrer vos raccourcis et « webNavigation » pour détecter, localement, une recherche sur un moteur supporté. Elle ne demande aucun accès au contenu de vos pages.

COMMENT L'UTILISER
1. Cliquez sur l'icône Link Catcher (ou Alt+Maj+L) puis ouvrez l'onglet « Nouveau ».
2. Saisissez un mot-clé (par exemple gh) et une URL (par exemple github.com).
3. Recherchez exactement ce mot dans votre moteur de recherche, ou tapez l + Espace + mot dans la barre d'adresse.
