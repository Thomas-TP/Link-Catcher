## Description détaillée (1826 caractères)
Link Catcher convierte tu barra de búsqueda en un lanzador para los sitios que visitas cada día.

Guarda una palabra clave y una URL (por ejemplo «gh» → github.com). Después escribe esa palabra en Google, Bing, DuckDuckGo, Yahoo, Ecosia, Brave, Startpage, Qwant o Kagi — o «l» + Espacio + palabra en la barra de direcciones — y llegarás directamente a tu página, incluso antes de que carguen los resultados.

FUNCIONES
• Redirección instantánea con una palabra exacta (sin distinguir mayúsculas ni acentos)
• Barra de direcciones (omnibox) con sugerencias en directo: «l», Espacio y unas letras
• Alias: escribe «docs, d» para crear dos palabras clave hacia el mismo enlace
• Búsqueda, orden (A-Z / Z-A), vista de lista o cuadrícula, orden manual arrastrando y soltando
• Importación / exportación de copias JSON, con gestión de conflictos (conservar las tuyas o reemplazar)
• Temas claro y oscuro; English, Français, Español, Deutsch
• Atajo de teclado Alt+Mayús+L para abrir el gestor
• Elige el buscador que se usa cuando una palabra no existe
• Contador de uso local en cada acceso (nunca se sincroniza)

PRIVACIDAD ANTE TODO
Sin cuenta, sin analíticas, sin seguimiento, sin código remoto, sin fuentes ni recursos externos. Tus accesos se quedan en tu navegador (los sincroniza tu navegador solo si activas la sincronización). La extensión solo necesita dos permisos: «storage» para guardar tus accesos y «webNavigation» para detectar, en local, una búsqueda en un buscador compatible. No pide acceso al contenido de tus páginas.

CÓMO USARLO
1. Haz clic en el icono de Link Catcher (o pulsa Alt+Mayús+L) y abre la pestaña «Nuevo».
2. Escribe una palabra clave (por ejemplo gh) y una URL (por ejemplo github.com).
3. Busca exactamente esa palabra en tu buscador, o escribe l + Espacio + palabra en la barra de direcciones.
